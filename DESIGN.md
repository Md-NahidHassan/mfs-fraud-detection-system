# Fraud operations design
The supplied plan establishes the visual authority: a restrained financial operations interface with a clean grid, compact readable tables, meaningful color, and no decorative effects.
Use Inter, a light workspace for desktop office review, a deep navy navigation rail, blue selected controls, and neutral bordered surfaces. Green means approved; amber means verification; red means critical risk. Main tasks are scanning alerts, examining rule evidence, and recording an analyst disposition.
Dashboard composition: summary counts, transaction volume and risk distribution, recent alerts, rule frequency, recipient and device risk. All displayed metrics derive from stored synthetic transactions.
Responsive navigation wraps into a compact horizontal menu. Tables scroll within their own containers. Forms collapse to one column. Every action has visible focus, errors, loading, and empty states.
